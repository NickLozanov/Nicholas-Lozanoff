
This file describes how I use AI tools in this repository.

## What I let AI help with
- Mechanical setup work: folder structures, boilerplate files, formatting
- First drafts I plan to heavily edit
- Research and summarizing background information

## What I do myself, first draft included
- Briefs (the scope and hypothesis before I start work)
- Analyses and the reasoning behind them
- Memos and recommendations (the decisions folder)
- Reflections on what I learned

## Review practice
- I read and edit every AI-generated file before committing it
- I do not commit AI output I haven't personally verified

## What does not get committed
- API keys, passwords, or credentials
- Personal/sensitive data not meant for a public repo
